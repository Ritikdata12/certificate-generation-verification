# Certify - Certificate Generation and Verification System

Certify is a powerful, user-friendly Certificate Generation and Verification System built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. The platform automates the creation, management, and verification of certificates, offering both admin and user-facing functionalities.

---

## Features

### Admin Panel
- Upload Excel files containing certificate data.
- Monitor upload logs and statuses.
- Secure role-based authentication for admins.

### Student Portal
- Search certificates using a unique Certificate ID.
- View certificate details dynamically.
- Download certificates as PDF files.

### Additional Features
- Dynamic certificate design using React components.
- PDF generation with libraries such as `pdfkit` or `jsPDF`.
- Real-time chat support using Tawk.io.
- Authentication using JWT for secure access.
